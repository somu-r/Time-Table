HTML TAGS Core Structure TagsEvery standard web document requires a foundational hierarchy to render correctly in a browser.: Declares the document type and ensures modern standards mode.: Acts as the root container for the entire document.: Holds machine-readable metadata, character sets, scripts, and stylesheet links.: Sets the text visible in the browser's tab or title bar.<body>: Encloses all visible content, including text, images, and components.Content and Layout TagsThese structural components divide and organize text across a layout.<h1> to <h6>: Establishes a heading hierarchy, where <h1> is the most important.<p>: Defines a block of text as a standard paragraph.<div>: Functions as a generic block-level container for CSS styling or grouping.<span>: Serves as a generic inline container to style specific chunks of text.<br>: Inserts a single line break without starting a new paragraph.Media, Links, and ListsThese interactive features enrich plain text documents with links and multimedia.<a href="URL">: Generates a hyperlink to navigate externally or internally.<img src="path" alt="text">: Embeds an image using a source file and alternate text.<ul>: Initializes a bulleted, unordered list of items.<ol>: Initializes a numbered, ordered list of items.<li>: Identifies an individual list item inside ordered or unordered lists.
